## Code Description

Lazado is a simple e-commerce website built using React JS. It allows users to browse products, filter products by category, add items to a shopping cart, view the total number of items, calculate the total price, and remove items from the cart.

## Features

- Homepage with a store header
- Reusable navigation buttons
- Four product categories
- Product cards with prices
- Add to Cart functionality
- Shopping cart with item count
- Automatic total price calculation
- Delete button for individual cart items
- Flexbox layout and responsive design

## Technologies Used

- React JS
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Run `npm install` in the project terminal.
2. Run `npm run dev`.
3. Open the local URL displayed in the terminal.

## Components

- `NavButton.jsx` - Reusable navigation button
- `Navbar.jsx` - Displays product categories
- `ProductCard.jsx` - Displays individual products
- `ProductSection.jsx` - Displays the product list
- `Cart.jsx` - Displays and manages the cart interface
- `App.jsx` - Main application and state management
